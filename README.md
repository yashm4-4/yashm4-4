# Hi, I'm Yash 👋

I'm a computational biologist working at the intersection of **machine learning, protein engineering, and genomics**. I enjoy both developing models to answer biological questions and building the scientific software that makes those models useful in practice.

I hold an **MS in Molecular Science and Software Engineering from UC Berkeley** and a **BS in Biology from UT Austin**.

### What I'm working on

- **NIH / National Library of Medicine:** Deep learning for regulatory genomics, enhancer prediction, and interpretation of noncoding genetic variants.
- **Augment Biologics:** Protein language models, antibody glycosylation prediction, Rosetta-based molecular modeling, and scalable computational workflows.

### Featured research

**[Regulatory Variant Modeling with AlphaGenome | NIH / National Library of Medicine](https://github.com/yashm4-4/nih-alphagenome-regulatory-variants-poster)**  
I led the computational research and created the approved NIH poster as its first author. The work combines CNN-based K562 enhancer classification, independent reporter-assay comparisons, and RNA/eQTL/chromatin evidence to prioritize candidate variant-to-gene relationships. A **first-author manuscript is in preparation**.

[**View the approved research poster (PDF)**](https://github.com/yashm4-4/nih-alphagenome-regulatory-variants-poster/blob/main/NIH_AlphaGenome_Poster_Yash_Maheshwaran.pdf) · [Project overview and contributions](https://github.com/yashm4-4/nih-alphagenome-regulatory-variants-poster)

**[Protein Machine Learning & Scientific Engineering | Augment Biologics](https://github.com/yashm4-4/yashm4-4/blob/main/research/augment-overview.md)**

Developed ESM2 (650M) fine-tuning workflows using PyTorch and LoRA for antibody glycosylation prediction. Conducted **70+ model runs** using protein-disjoint evaluation and optimized inference costs by approximately **5.5×** for the longest inputs. Engineered scalable **Rosetta ΔΔG screening workflows for 25,000+ antibody Fc variants** using Modal and AWS S3.
